COMANDOS UTILES
---------------
Descargar dependencias:
    flutter pub get

Ejecutar pruebas:
    flutter test

Verificar codigo:
    flutter analyze

Compilar web:
    flutter build web --release

Compilar APK ofuscado para pruebas en PowerShell:
    $env:JAVA_HOME = "$env:ProgramFiles\Android\Android Studio\jbr"
    $env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
    flutter build apk --release --obfuscate --split-debug-info=build/symbols

Salida:
    build/app/outputs/flutter-apk/app-release.apk

El build actual usa la clave debug y el applicationId provisional
com.example.flutter_prestamos. Definir un applicationId definitivo y configurar
una keystore release antes de distribuir el APK a clientes. Guardar
build/symbols para diagnosticar errores del codigo ofuscado; no publicar esos
simbolos.

DESPLIEGUE WEB CON DOCKER
-------------------------
Construir imagen:
    docker build -t gotacontrol-web .

Probar localmente en http://localhost:8080:
    docker run --rm -e PORT=10000 -p 8080:10000 gotacontrol-web

RENDER
------
Crear un Web Service conectado al repositorio JULIANLINARES77/CrediGota,
seleccionar Docker como runtime y usar la raiz del repositorio como contexto.
Render inyecta PORT (por defecto 10000) y Nginx escucha ese puerto.

Para publicar en un dominio, configurar HTTPS en el proxy inverso o proveedor
de hosting. La persistencia SQLite actual funciona en Android; el target Web
no incluye un adaptador SQLite de navegador ni backend compartido.
